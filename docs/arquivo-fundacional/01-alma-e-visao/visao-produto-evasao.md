## 1. O Problema Central: Evasão Escolar em Angola

A evasão universitária não é uma estatística abstrata. É uma tragédia humana com 4 dimensões:

- **Dimensão Humana:** Frustração, perda de confiança, impacto psicológico, estigma social. Muitos nunca mais tentam o ensino superior.
- **Dimensão Institucional:** Vagas desperdiçadas, investimento perdido em infraestrutura e docentes.
- **Dimensão Económica:** Angola precisa urgentemente de profissionais em Engenharia, Saúde, Tecnologia, Gestão. Cada profissional qualificado gera retorno de 5-10x.
- **Dimensão Social:** Perpetua ciclos de desigualdade — jovens de comunidades menos privilegiadas são mais vulneráveis.

## 2. O PDC como Infraestrutura de Decisão

O PDC não é um "teste vocacional" — é uma infraestrutura que gera **evidência comportamental** para reduzir decisões vocacionais equivocadas.

### O Fluxo Core

```
Experiência (Sentir) → Simulação (Testar) → Perfil Vocacional (Medir)
→ Recomendação (Decidir) → Vínculo (Agir)
```

### O que mede (o "músculo")

- **Fluidez Cognitiva (φ):** Velocidade e suavidade com que o estudante resolve problemas.
- **Resiliência (R):** Capacidade de recuperar após erros.
- **Estabilidade de Foco:** Consistência de atenção ao longo de uma simulação.
- **Hesitação:** Padrões de dúvida e tempo morto.

## 3. Valor para Cada Público

### Estudante Pré-Universitário (Core)
- Experimentar antes de escolher, com dados reais e feedback imediato.
- Veredito vocacional com explicabilidade: score, arquétipo, próximo passo.

### Estudante Universitário (o que "já decidiu")
1. **Validação de Rota:** Distinguir "falta de base" de "falta de aptidão" — diagnóstico de sobrevivência académica.
2. **CV do Futuro:** Perfil Vocacional como anexo ao diploma — "a minha resiliência sob pressão é de 0.95".
3. **Especialização:** Bússola de nicho dentro de cursos genéricos (ex: Gestão → Financeiro vs RH vs Operações).
4. **Mentoria:** Ligação a mentores de elite via vínculos para preparar-se para o mercado real.
5. **Seguro contra Evasão:** Identificar alunos em risco (telemetria de frustração) antes que abandonem.

### Instituição
- Ferramenta de **retenção** — intervir proactivamente em alunos de risco.
- **Estudantes pré-validados** — "500 alunos com 95% de compatibilidade com o vosso curso de Engenharia".

### Mentor
- Visibilidade perante instituições.
- Feedback técnico com dados reais, não opinião.

### Investidor/Patrocinador
- Investir em **padrões de comportamento validados**, não em "nomes".
- "Talent Bounties" — recompensas por atingir scores em áreas críticas.

## 4. O Mantra de Vendas

> "O PDC não é um lugar para estar; é um lugar para ser validado. Nós não medimos o que o aluno diz que sabe; nós medimos o que o aluno faz quando ninguém está a olhar."

> "Não queremos que todos repensem as suas decisões. Queremos que todos optimizem a sua trajectória."

## 5. Preocupações Pré-Lançamento (Diagnóstico Real)

Lista de problemas identificados que devem ser resolvidos antes do lançamento:

- **Seed narrativo:** Plataforma vazia não convence ninguém — precisa de dados que simulem uso real.
- **Dashboard fraca:** Parece área de configuração, não storytelling de progresso.
- **Loops de carregamento:** Algumas páginas dão erro quando não há conteúdo.
- **Relatório vocacional escondido:** É o core do produto mas tem o design mais fraco.
- **Perfil é só configuração:** Não dá para ver como os outros nos vêem.
- **Estrutura de relatório indefinida.**
