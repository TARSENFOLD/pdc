# Guia do Comité Científico

O Comité Científico é responsável pela validação académica do conteúdo da plataforma.
Garante que as simulações e experiências são baseadas em evidência real, não especulação.

## Responsabilidades

- Validar Simulações antes de serem publicadas (verificar rigor académico)
- Validar Experiências institucionais (verificar autenticidade dos depoimentos)
- Aprovar ou rejeitar conteúdo com comentário fundamentado

## Acesso

Zona própria: /app/comite
- Dashboard: fila de validação pendente
- Validação Científica: lista de simulações/experiências aguardando aprovação

## Fluxo de Validação

1. Mentor/Instituição submete conteúdo para revisão (estado: review)
2. Comité recebe notificação
3. Comité analisa o conteúdo
4. Comité aprova (estado: approved) ou rejeita com motivo (estado: draft)
5. Autor recebe notificação com resultado
