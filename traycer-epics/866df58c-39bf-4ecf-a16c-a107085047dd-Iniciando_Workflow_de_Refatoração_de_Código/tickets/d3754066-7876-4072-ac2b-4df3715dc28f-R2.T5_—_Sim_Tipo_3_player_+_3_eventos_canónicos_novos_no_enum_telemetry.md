# R2.T5 — Sim Tipo 3 player + 3 eventos canónicos novos no enum telemetry

### Scope & Objective

Criar o **shell funcional** do `Tipo3Player.tsx` (componente novo, isolado em `features/simulacoes/`) + extender o enum canónico de telemetria com 3 nomes novos para o ciclo de vida deste player + remover o `Wrench` placeholder do `SimulacaoPlayerPage`.

**In scope:**

| Ficheiro | Acção | Razão |
| --- | --- | --- |
| file:apps/web/src/features/simulacoes/Tipo3Player.tsx | NOVO | Shell renderiza simulação interactiva, emite `simulacao.tipo3.{iniciada,acao,concluida}` via `useTelemetry`, chama `simulacoesApi.concluirTentativa({metadata})` no fim (sem `score` — derivação BFF de R2.T4 aplica também) |
| file:packages/shared/src/telemetry.ts | EXTEND | Adicionar `'simulacao.tipo3.iniciada'`, `'simulacao.tipo3.acao'`, `'simulacao.tipo3.concluida'` a `TelemetriaTipoSchema` (Approach §1.4) |
| file:apps/web/src/features/simulacoes/SimulacaoPlayerPage.tsx | MODIFY | Quando `tipo === 3` renderiza `<Tipo3Player>`; remover ícone `Wrench` placeholder |
| file:apps/web/src/features/simulacoes/Tipo3Player.spec.tsx | NOVO | Smoke test: renderiza, emite os 3 eventos via `useTelemetry` spy |
| file:tests/e2e/simulacoes/tipo3.spec.ts | NOVO | Smoke e2e: navegar para simulação `tipo=3` mostra player |
| file:infra/strapi/scripts/seed-narrativo.ts (ou nova fixture) | EXTEND | Garantir `≥1` simulação `tipo=3` no seed |

**Out of scope:**

- **Conteúdo real** (cenários, scoring específico de Tipo 3) — fica para ticket de produto futuro (Approach §1.5 New Concerns: "shell funcional; conteúdo real out-of-scope")
- Backfill de tentativas Tipo 3 históricas

### Guardrails

- **Não introduzir GSAP** nem outras libs pesadas (guardrail explícito atlas)
- `Tipo3Player` ≤ 300 linhas (Constitution v2.1)
- Eventos novos do enum **só adicionados**, nunca renomeiam/removem existentes (Invariant §4 Contratos)
- Player usa `useTelemetry` (já validado em W0-T3) — não bypassa para `fetch` directo

### Acceptance Criteria

- `Tipo3Player.tsx` renderiza sem erros para qualquer simulação `tipo=3`
- Spy de `useTelemetry` regista os 3 eventos canónicos novos
- E2E `tipo3.spec.ts` verde
- `SQL SELECT COUNT(*) FROM tentativas WHERE simulacao.tipo=3` ≥ 1 após seed (validação manual ou automatizada)
- `SimulacaoPlayerPage` já não mostra ícone `Wrench` para `tipo=3`
- `npm run lint && npm run typecheck && npm test` verde
